## Part B — The 10× Levers (what makes this ten times better)

1. **Dream Center as a true product** — 7-step configurator with live visual preview, investment estimate, PDF export, and booking handoff.
2. **City × Service SEO matrix** — 9 city pages replacing the single "service area" paragraph; owns local intent queries like *"luxury pool builder Scottsdale."*
3. **Signature project storytelling** — each portfolio item is a 600-word editorial ("The Harrison Residence — Paradise Valley") with photography-first layout, not a gallery row.
4. **Trust stack above the fold** — ROC license, BBB, NPC, 5★ Google, years in business, projects delivered, all in a thin luxury bar under the hero.
5. **Video everywhere appropriate** — 15-second hero loop, 60-second founder film on About, project walkthroughs on portfolio detail pages.
6. **Lead magnet funnel** — gated "Arizona Dream Backyard Playbook" PDF → 5-part email nurture → Dream Center invitation.
7. **Booking gate** — consultation calendar is a native Wix Bookings flow (15-min intro call → 60-min on-site design visit), not a form.
8. **Financing transparency** — real calculator on `/financing` (monthly payment on $85k over 180 months at X%) — removes the price objection.
9. **Referral engine** — `/referral-program` offers existing clients $500 credit / free maintenance quarter when their referral signs a contract.
10. **Measurable funnel** — GA4 + Clarity heatmaps + conversion events on every meaningful click (Dream Center start, step complete, estimate shown, book-call click).

### D4. Velo implementation

**Frontend** — 7 Wix Studio sections, only one visible at a time; state held in `$w` scope.

**Backend `dream-center.jsw`:**
```javascript
import wixData from 'wix-data';
import { fetch } from 'wix-fetch';
import { getSecret } from 'wix-secrets-backend';

export async function saveDreamSubmission(payload) {
  // 1. Save to DreamSubmissions collection
  const saved = await wixData.insert('DreamSubmissions', {
    ...payload,
    submittedAt: new Date(),
    estimate: calculateEstimate(payload),
    matchedPortfolioId: await matchPortfolio(payload)
  });

  // 2. Send to GoHighLevel via Inbound Webhook
  const ghlWebhookUrl = await getSecret('GHL_WEBHOOK_URL');
  await fetch(ghlWebhookUrl, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(mapToGHL(payload, saved))
  });

  // 3. Send internal notification email
  // 4. Return confirmation + matched portfolio
  return { ok: true, matchId: saved.matchedPortfolioId, estimate: saved.estimate };
}
```

**Estimate function** — pure function, unit-tested, in `backend/estimator.jsw`.
